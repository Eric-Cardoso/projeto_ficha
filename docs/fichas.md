# 🧾 Fichas

## Funcionalidades:

- criar ficha
- listar fichas
- listar ficha específica
- atualizar ficha
- atualizar parcialmente ficha
- deletar ficha

## Regras:

- cada usuário pode possuir no máximo 20 fichas
- usuários só podem acessar suas próprias fichas
- administradores possuem permissões separadas
- admins podem visualizar fichas de qualquer usuário
