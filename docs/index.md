# 🧾 Projeto Fichas API

# 📌 Descrição

API REST desenvolvida com FastAPI para gerenciamento de usuários e fichas.

A aplicação possui autenticação JWT, sistema de permissões entre usuários e administradores, cache com Redis e gerenciamento completo de fichas.

O projeto segue uma arquitetura em camadas, separando responsabilidades entre rotas, serviços e acesso ao banco de dados.
