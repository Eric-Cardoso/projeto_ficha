# 🛡️ Administração

O sistema possui rotas administrativas separadas das rotas comuns.

## Funcionalidades:

- listar usuários
- listar usuário específico
- atualizar usuários
- deletar usuários
- listar fichas de qualquer usuário
- listar ficha específica de qualquer usuário

## Regras:

- apenas usuários administradores possuem acesso
- rotas admin exigem autenticação JWT
- admins não podem alterar fichas diretamente
